# MayPatrol — סרטון מותאם אישית עם כתוביות בעברית

פרויקט להפקת סרטון בן כשתי דקות, מבוסס על תמונות שסופקו, עם כתוביות צרובות בעברית.

## מבנה הפרויקט

```
assets/images/   התמונות שסופקו (קלט ליצירת הקטעים)
clips/           קטעי הווידאו שנוצרו — ממוספרים לפי סדר: 01_, 02_, ...
subtitles/       קובצי כתוביות בפורמט SRT
output/          הסרטון הסופי
scripts/         סקריפטים להרכבה
.build/          קבצי ביניים (נוצר אוטומטית, לא נשמר ב-git)
```

## התקנה

```bash
./scripts/setup.sh
```

מתקין `ffmpeg` סטטי ומוודא שהוא נבנה עם `libass` ו-`libfribidi` — שתי הספריות
שאחראיות על עיבוד נכון של כתוביות בעברית.

## הרכבת הסרטון

```bash
./scripts/build_video.sh
```

או עם נתיבים מפורשים:

```bash
./scripts/build_video.sh subtitles/final.srt output/final.mp4
```

הסקריפט עושה שלושה דברים:

1. **נרמול** — כל הקטעים מומרים ל-1920x1080 ב-24 fps עם פס קול אחיד.
   הצעד הזה הכרחי: קטעים ממודלים שונים מגיעים ברזולוציות ובקצבי פריימים שונים,
   וללא נרמול החיבור ביניהם נכשל או יוצא משובש. קטעים שאינם ביחס 16:9
   ממורכזים עם פסים שחורים במקום להימתח.
2. **חיבור** — כל הקטעים מחוברים לפי סדר אלפביתי של שמות הקבצים.
3. **צריבת כתוביות** — הכתוביות נצרבות לתוך התמונה.

## כתוביות בעברית

הטקסט ב-SRT נכתב **בסדר לוגי רגיל** — כותבים עברית כרגיל, משמאל לימין בקובץ.
אין להפוך אותיות ידנית. `libfribidi` מיישם את אלגוריתם ה-bidi בזמן הצריבה
ומסדר את הטקסט מימין לשמאל, כולל מיקום נכון של סימני פיסוק בקצה השורה.

דוגמה:

```srt
1
00:00:00,500 --> 00:00:03,500
מאי וכלבי המשמר יוצאים להרפתקה!
```

### הנחיות לכתוביות לילדים

- שורה אחת או שתיים לכל כתובית, עד ~40 תווים בשורה.
- כתובית מוצגת לפחות 1.5 שניות, גם אם המשפט קצר.
- להשאיר רבע שנייה לפחות בין כתוביות עוקבות.

### שינוי עיצוב הכתוביות

ההגדרות נמצאות בראש `scripts/build_video.sh`:

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `FONT` | `DejaVu Sans` | פונט עם כיסוי עברי מלא |
| `FONTSIZE` | `42` | גודל הפונט |
| `MARGIN_V` | `60` | מרחק מתחתית המסך |
| `WIDTH` / `HEIGHT` | `1920x1080` | רזולוציית הפלט |
| `FPS` | `24` | קצב פריימים |

## הערה על יצירת הקטעים

הקטעים עצמם נוצרים דרך Higgsfield. מודלי תמונה-לווידאו מפיקים קטעים קצרים
(בערך 5–10 שניות), ולכן סרטון של שתי דקות מורכב מכ-12 עד 24 קטעים נפרדים.
לאחר יצירת כל קטע יש לשמור אותו בתיקיית `clips/` עם קידומת מספרית שקובעת
את סדר ההופעה בסרטון הסופי.
